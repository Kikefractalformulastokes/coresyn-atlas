# Validation Readiness File — CCFA001 Cosmology

**VRF ID:** VRF-CCFA001  
**Lifecycle:** DONE — pending independent CMOS review  
**Acceptance:** NOT SELF-ACCEPTED  
**Readiness distance:** 1

## Exact claim
A real-data cosmology pipeline over the 2M++ density and velocity cubes is internally reproducible: the frozen code path passes its test suite and the full-data validation checks, while preserving explicit distinction between internal reproduction and independent validation.

## Real state
The executable and data bundles have been recovered from the CoreSyn Library. The data ZIP contains the declared density and velocity NPY cubes. Their hashes agree with the internal audit bundle. The full pipeline has been rerun over the real cubes.

The original package depended on `astropy.stats.mad_std` but did not provide an exact environment lock. In an environment without Astropy, 17 of 21 collected tests failed for the missing dependency rather than for numerical assertions. A compatibility run using an equivalent robust-MAD implementation isolated that dependency defect and the remaining suite passed. A candidate internal revision removed the unnecessary Astropy dependency in favour of the already-declared scientific stack; that candidate passed 22/22 tests and completed the full-data pipeline.

No independent third party has reproduced or validated the result.
