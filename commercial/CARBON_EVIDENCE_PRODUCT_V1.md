## Product category

CoreSyn Carbon Evidence is not a carbon calculator and is not an accredited verification opinion unless CoreSyn later acquires the relevant accreditation.

It is an independent evidence-assurance and pre-verification service over a carbon footprint already calculated by the client, consultant, ERP or carbon-accounting platform.

Core promise:

"Ya has calculado tu huella. CoreSyn comprueba si puedes demostrarla."

## What CoreSyn checks

### A. Boundary Gate
- legal / organisational boundary consistency
- site coverage
- source inclusion/exclusion logic
- year consistency

### B. Activity Data Gate
- evidence exists for material activity data
- units are coherent
- duplicates / omissions / unexplained gaps
- source-document linkage

### C. Emission Factor Gate
- correct factor family
- correct year/version
- geography / energy source / fuel applicability
- unit conversion
- factor provenance

### D. Calculation Gate
- formula checks
- independent recalculation of material lines
- aggregation consistency
- conversion errors
- rounding / sign / duplicate-count checks

### E. Evidence Gate
- every material figure linked to evidence or explicitly marked unsupported
- evidence age / period
- contradictions
- missing documents

### F. Year-on-Year Gate
If prior year is available:
- material changes
- unexplained jumps
- methodology change
- boundary drift

## Deliverables

### 1. Corrected / annotated workbook
Client workbook returned with CoreSyn comments / exception references. CoreSyn does not silently alter the client's authoritative file; corrections are traceable.

### 2. Carbon Evidence Report
Professional PDF report containing:
- executive conclusion
- reviewed scope
- methodology used by client
- major findings
- material exceptions
- factor review
- data-evidence map
- reproducibility result
- limitations
- remediation list

### 3. Evidence Register
Table mapping:
Claim / value → source → factor → formula → status → exception → owner / action.

### 4. Carbon Evidence Card
One-page management summary designed for CEO/CFO/Environmental Manager.

### 5. Gate result
Per block:
PASS / CONDITIONAL / HOLD / FAIL / NOT TESTED.

No global PASS is issued if a material block is HOLD, FAIL or NOT TESTED.

## Minimum evidence standard

Every material reviewed line must have:
- value
- unit
- period
- source
- factor
- factor version/year
- formula
- evidence status
- reviewer status

If any required field is absent, status cannot be PASS.

## QA rules

- no silent data repair
- no retrospective changing of acceptance criteria to create a PASS
- every exception has severity and disposition
- every material conclusion has traceable support
- version all external factors and methodology references
- preserve original client file
- retain review log according to data-retention policy

## Data security requirements

Before first paid delivery:
- standard NDA
- secure upload route
- client-specific access permissions
- retention/deletion terms
- no client evidence used for model training without explicit written permission
- audit log for file access and final outputs
